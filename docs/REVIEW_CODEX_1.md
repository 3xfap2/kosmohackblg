### Предлагаемое исправление (решать Codex, это его папка)

1. **Базовое правило для сравнения оставить EDF** — постановка прямо допускает «по ближайшему сроку».
2. **Основной планировщик строить поверх сильной эвристики**, зависящей от цели:
   «priority» — приоритет → запас/срок, «revenue» — ценность на шаг работы; не брать безнадёжные задания.
3. **CP-SAT — улучшение поверх эвристики:** `AddHint` планом эвристики на окне (решатель стартует
   с хорошего решения), лимит 0,5–1 с детерминированного времени; страховка сравнивает с эвристикой,
   а не с EDF. Проверить время смены P02/P04 (на Vercel считаем кусками по 240 с).
4. В `results/` показать вклад каждой части: EDF → эвристика → эвристика + CP-SAT, по обеим целям,
   с честными случаями «равно».
