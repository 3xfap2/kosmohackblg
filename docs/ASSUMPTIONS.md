# Допущения команды

Это **не условия организатора**, а настройки и допущения нашего решения. Каждое — с причиной
и способом проверки. Значения меняются только с записью здесь и в `CRITERIA.md`.

| ID | Допущение | Значение | Почему | Как проверяем | Владелец |
|---|---|---|---|---|---|
| A1 | Окно планирования CP-SAT | 48 шагов (4 ч) | Максимальное окно задания — 29 шагов; орбита ≈ 19 шагов (12 свет + 7 тень) — окно покрывает ~2,5 витка | Чувствительность 24/36/48/72 в `results/` | Codex |
| A2 | Период плановой перестройки | каждые 6 шагов + при событии, смене цели, отказе действия | Баланс времени расчёта и свежести плана | Сравнение 1/3/6/12 | Codex |
| A3 | Ценность остатка энергии в конце окна | 0,5 $/Вт·ч | Без неё окно разряжает батареи перед своей границей | Чувствительность 0 / 0,25 / 0,5 / 1 | Codex |
| A4 | Вес задания приоритета 3 в режиме «Приоритетное обслуживание» | 100 000 $ за задание (лексикографически выше выручки) | Постановка: «основная цель — P3 в срок; при сопоставимом выполнении — выручка» | Сравнение целей на P02/P03 | Codex |
| A5 | Прогноз температуры внутри планировщика | по траектории ожидания | Упрощение; итог всегда считает модель организаторов. **Требует проверки:** консервативность по энергии (нагреватель, зарядка) и отсутствие сюрпризов по верхнему пределу 45 °C | Доля отклонённых моделью плановых действий по причинам `energy_reserve` / `thermal_limit` | Codex |
| A6 | Детерминированность решателя | [выбирается] seed + детерминированный лимит | Т4: повтор запуска → те же команды | Двойной прогон, сравнение хешей команд | Codex |
