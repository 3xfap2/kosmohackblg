# Дизайн — Resend («black velvet with violet neon»), адаптация под «Созвездие»

Источник: Refero Styles, стиль Resend (файл DESIGN1.md от пользователя). Ниже — только то, что
применяем, и как стиль ложится на консоль оператора.

## Принципы

- Холст — чистый чёрный `#000000`. Слои разделяются линией 1px `#292d30`, без теней.
- Кнопки — «призраки»: прозрачные, рамка 1px, белый текст, радиус 6px. Заливка — только у одной
  главной кнопки действия на экране (`#3b9eff`).
- Радиусы: 6px — кнопки, бейджи, поля; 16px — карточки и панели. На одной поверхности — один радиус.
- Моноширинный шрифт — для всех идентификаторов и чисел журнала: `S01`, `JOB-0001`, шаг `072`, `83.4 Вт·ч`.
- Фиолетовый `#9281f7` — только идентификаторы (аппараты, задания, события), не заголовки.
- Цветные — только статусы данных. Никаких градиентов в интерфейсе, кроме героя лендинга.

## Токены

```css
:root {
  --bg: #000000;             /* холст */
  --surface: #0b0e14;        /* поднятые панели, подсказки */
  --line: #292d30;           /* все границы */
  --text-strong: #ffffff;    /* заголовки */
  --text: #f0f0f0;           /* основной текст */
  --text-muted: #a1a4a5;     /* подписи, метаданные */
  --text-faint: #6e727a;     /* отключённое */
  --id: #9281f7;             /* идентификаторы */
  --action: #3b9eff;         /* единственная залитая кнопка */

  /* статусы данных */
  --ok: #3ad389;             /* выполнено в срок */
  --info: #70b8ff;           /* downlink, в работе */
  --relay: #baa7ff;          /* ретрансляция */
  --warn: #ffca16;           /* калибровка, предупреждение о дефиците */
  --bad: #ff9592;            /* просрочено, отказ */

  --font-sans: "Inter", system-ui, sans-serif;
  --font-display: "Inter Tight", "Inter", sans-serif;        /* замена aBC Favorit, есть кириллица */
  --font-serif: "Playfair Display", Georgia, serif;          /* замена Domaine, только герой лендинга */
  --font-mono: "JetBrains Mono", ui-monospace, monospace;    /* замена Commit Mono, есть кириллица */

  --r-sm: 6px; --r-lg: 16px;
  --page: 1200px;
}
```

Шкала текста: 12 / 14 / 16 / 20 / 24 / 56 (заголовок секции, −0.05em) / 96 (герой, −0.01em).
Отступы кратны 4px; секции лендинга — 96px, карточки — 32px, элементы — 16px.

## Как это ложится на продукт

| Элемент | Решение |
|---|---|
| Диаграмма Ганта (аппарат × шаг) | Чёрные ячейки, линии `--line`; relay — `--relay`, downlink — `--info`, калибровка — `--warn`, отказ — штрих `--bad` |
| Графики заряда | Линия `--text`, резерв 30% и критический 20% — пунктир `--warn` / `--bad`, тень — полоса `--surface` |
| Статусы заданий | Точка 6px + подпись моноширинным: `● выполнено`, `● просрочено` |
| Сообщения (события) | Окно-«терминал»: рамка, радиус 16px, моно 13px; ошибка — строка `--bad` |
| Лендинг | Герой: заголовок serif 96px + созвездие из 48 точек-аппаратов на чёрном (в духе Dala), без градиентного фона |

Дизайн не полируем, пока в `CRITERIA.md` есть незакрытые критерии.
