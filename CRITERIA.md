# Критерии → доказательства

Кейс «Автономное управление спутниковой группировкой», КосмоХакатон 2026. Для каждого критерия —
где это реализовано, как проверить и какой результат. Числа — из `results/summary.json`
(32 прогона в официальной модели: P01–P04 × 3 алгоритма × 2 цели и P02 с сообщениями × 4 варианта × 2 цели), `results/extended_summary.json` (отдельный эксперимент),
`results/demo_losses.json`. Проверка всего сразу: `python -m pytest -q` (126 тестов, включая повтор 32 сохранённых выгрузок).

## Ограничения (сказаны явно)

- Модель — расчётная, не телеметрия; расширенная модель — допущения команды A11–A13, её результаты не смешиваются с официальными.
- Страховка CP-SAT (A7) сравнивает с эвристикой на окне 48 шагов по цели — это проверка окна, не гарантия итога суток.
- CP-SAT в коммерческом режиме P04 не принят ни разу (0 из 48): итог равен эвристике.
- Защита заряда в тени (эвристика 1.3) в приоритетном режиме P04 стоит 3 срочных из 1692 (1652 → 1649); ниже резерва 533 → 293.
- Учёт цены ориентации при выборе исполнителя даёт малый и не всегда положительный эффект (P02 +$120, P03 −2 срочных).

Рабочие журналы команды (`docs/HANDOFF.md`, `docs/REVIEW_CODEX_1.md`, `docs/PROPOSAL_O7.md`) описывают ход разработки
на момент записи; итоговое состояние — этот файл и `README.md`.
